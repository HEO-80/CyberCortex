# CyberCortex 🧠

> Second brain / knowledge graph de Hector Eduardo Oviedo

## Estructura
```
CyberCortex/
├── 0-Inbox/          ← captura rápida
├── 1-Areas/          ← proyectos activos
├── 2-People/         ← personas
├── 3-Topics/         ← dominios personales
├── 4-Teaching/       ← módulos docentes
├── 5-Resources/      ← referencias externas
├── 6-Archive/        ← proyectos cerrados
├── _Templates/       ← plantillas de nota
└── _MOC/             ← Maps of Content
```

## Sync
Este vault se sincroniza entre ordenadores via Git.

```bash
# Pull antes de trabajar
git pull

# Push al terminar
git add -A && git commit -m "sync" && git push
```
