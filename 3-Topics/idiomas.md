# 🗣️ Idiomas

> Inglés en curso (A2-B1 → B2/C1) · Francés después

## Inglés
- Nivel actual: A2-B1 estimado
- App EWA para lectura
- Amiga suiza para speaking (habla inglés y francés)
- Libro: "English Grammar in Use" 5ª ed. (Murphy, B1-B2) → "Advanced Grammar in Use" (Hewings, C1-C2)
- Objetivo: B2 First de Cambridge → C1 Advanced
- Prefiere estudiar desde PC (eBook/online)

## Francés
- Empezar a partir del B2 de inglés
- Recurso: "Grammaire progressive du français" (Débutant → Intermédiaire → Avancé)
- Práctica con amiga suiza
