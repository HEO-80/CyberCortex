# 🌍 SRI — Servicios de Red e Internet

> 2º ASIR · 8 unidades completas con tutoriales paso a paso + Docker

## Unidades
1. **DNS** — BIND, una sola VM
2. **DHCP** — servidor + cliente (dos VMs)
3. **Servidores Web** — Apache (no Nginx)
4. **FTP** — vsftpd + SFTP
5. **Correo** — Postfix (SMTP) + Dovecot (POP3/IMAP)
6. **Mensajería/Noticias/Listas** — investigación teórica + Mailman opcional
7. **Audio Streaming** — Icecast + VLC
8. **Vídeo Streaming** — FFmpeg + Nginx HLS (VOD y directo)
- **Extra:** Introducción a Docker (contenedores vs VM, docker run, docker-compose, BIND en Docker)

## Metodología
- Enfoque práctico con VMs Linux
- Tres piezas por unidad: tutorial guiado, proyecto de unidad, rúbrica
- Proyecto integrador final: DNS + DHCP + web + correo (+ extras opcionales con Docker)
