# 🎯 QuickTest Exam

> Simulador de exámenes de certificaciones (Azure + AWS) y oposiciones con vigilancia automática

## Descripción
Plataforma SaaS de tipo test con corrección automática, simulación de exámenes reales y vigilancia de trampas.

## Módulos
- **Certificaciones cloud:** Azure (AZ-104, AZ-900, AI-200) + AWS (CLF-C02, SAA-C03, SOA-C02)
- **Oposiciones:** módulo de oposiciones informáticas (TAI AGE, TAI Ayto Zaragoza)
- **772+ preguntas** ya cargadas

## Features
- Vigilancia automática (tab change, copy/paste, window blur)
- Modo examen con temporizador
- Histórico de resultados y progreso
- Sistema de pistas y explicaciones

## Stack técnico
- Next.js + TypeScript + MongoDB
- Auth con NextAuth
- Deploy en Vercel
